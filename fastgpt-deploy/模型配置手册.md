# FastGPT 模型配置手册（适配本部署：v4.9.13 + AI Proxy）

> 适用：本目录 docker-compose.yml 起的 FastGPT。
> 架构：**FastGPT 主程序不直连任何模型厂商**，所有请求经 AI Proxy 网关转发。
> 更新：2026-09-14

```
FastGPT(3000) ──> aiproxy(3001) ──> 智谱 / DeepSeek / SiliconFlow ...
```

## 一、登录 AI Proxy 管理台

1. 浏览器打开：`http://<服务器IP>:3001`
2. 密码 = compose 里的 `ADMIN_KEY`，本部署当前值为 `aiproxy`
   - ⚠️ 这是弱默认值，建议改掉：改 `docker-compose.yml` 中 `ADMIN_KEY` 后 `docker compose up -d aiproxy` 重建
   - 注意同步改 FastGPT 容器的 `AIPROXY_API_TOKEN`（两处必须一致，否则聊天报"模型异常"）

## 二、添加渠道（Channel）= 接入一个模型厂商

管理台左侧 **渠道管理 → 新建渠道**，按厂商填：

| 填写项 | 智谱（推荐主力） | DeepSeek | SiliconFlow（推荐向量） |
|---|---|---|---|
| 类型 | openai（兼容格式） | openai | openai |
| 名称 | zhipu | deepseek | siliconflow |
| Base URL | `https://open.bigmodel.cn/api/paas/v4` | `https://api.deepseek.com/v1` | `https://api.siliconflow.cn/v1` |
| 密钥 | 智谱 API Key | DeepSeek API Key | 硅基流动 API Key |
| 模型 | 见下方"模型清单" | `deepseek-chat` | `BAAI/bge-m3` |

> 智谱/DeepSeek 的接口都是 OpenAI 兼容格式，所以渠道类型统一选 openai 即可。

**模型清单（逗号分隔，直接粘贴进"模型"框）——智谱渠道：**

```
glm-5.3,glm-5.3-flash,embedding-3
```

## 三、FastGPT 需要哪几类模型（角色）

| 角色 | 用途 | 推荐 | 不配的后果 |
|---|---|---|---|
| 对话模型 | 聊天/工作流 LLM | `glm-5.3`（贵但强）/ `glm-5.3-flash`（免费） | 无法对话 |
| **索引模型** | 知识库向量化（必配！） | `BAAI/bge-m3` 或 `embedding-3` | **知识库无法训练** |
| QA 模型 | 文档自动拆问答对（可选） | `glm-5.3-flash` | 不能用"问答拆分"导入模式 |
| 图片理解 | 看图（可选） | 智谱 glm-4v 系列 | 图片理解节点不可用 |
| 语音 | TTS/STT（可选） | 暂缺可后补 | 语音输入输出不可用 |
| Rerank | 检索重排（可选，检索质量↑） | SiliconFlow `BAAI/bge-reranker-v2-m3` | 检索用默认排序 |

## 四、在 FastGPT 里选定默认模型

渠道建好后回 FastGPT（端口 3000）：

1. 左下角头像 → **管理端 → 模型管理**：确认上一步配的模型已出现在列表（有单价/分组就说明通了；看不到=渠道模型清单没填对）
2. 团队级默认：头像 → **团队管理 → 模型配置**，把「默认对话模型」「文件理解模型」设为 `glm-5.3`，**向量模型设为 `BAAI/bge-m3` 或 `embedding-3`**
3. 应用级覆盖：每个应用的「关联模型」里可单独换（比如便宜应用用 flash）

## 五、验证链路（2 分钟）

1. FastGPT 里新建一个「简易应用」→ 直接发一句"你好"→ 正常回复 = 对话链路 ✅
2. 新建知识库 → 随便传一个 txt → 训练完成不报错 = 向量链路 ✅
3. AI Proxy 管理台 → 「日志」页：能看到每条请求的耗时/消耗/状态码，报错在这里看最直接

## 六、常见故障速查

| 症状 | 原因 | 处理 |
|---|---|---|
| FastGPT 里没有模型可选 | 渠道的"模型"框没填/名字打错 | 回渠道编辑，模型名必须与厂商 API 完全一致（区分大小写） |
| 聊天报"模型异常/401" | 渠道密钥错误；或改过 ADMIN_KEY 但 `AIPROXY_API_TOKEN` 没同步 | 核对两处 token；日志页看真实报错 |
| 知识库训练报错/无向量模型 | 没配 embedding 或团队默认向量模型没选 | 补第三节的索引模型并设为默认 |
| 响应巨慢 | 走了 flash 免费档限流；或 Base URL 填了非国内节点 | 换 glm-5.3；核对各厂商 Base URL |
| 打开 3001 白屏 | aiproxy 容器没起来 | `docker compose logs aiproxy` 排查 |

## 七、成本参考（按量，元/百万 token）

| 模型 | 输入 | 输出 | 用途建议 |
|---|---|---|---|
| glm-5.3 | ~1.4 | ~4.4 | 主力对话 |
| glm-5.3-flash | ~0.15 | ~0.5 | QA 拆分/便宜应用 |
| deepseek-flash | 2（命中 0.04） | 8 | 备用 |
| bge-m3 | 免费档 | — | 向量化 |

> 知识库的向量成本只发生在导入/重建索引时一次，查询时只算对话模型的输入 token——文档量不大时 embedding 几乎免费。

## 附：改完配置怎么生效

- 改**渠道/模型**（AI Proxy 网页操作）：即时生效，无需重启
- 改 **docker-compose.yml**：`docker compose up -d` 重建对应服务
- 改 **config/config.yaml**：`docker compose restart fastgpt`
