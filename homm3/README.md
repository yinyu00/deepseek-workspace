# 英雄无敌3 复刻版（Python + Pygame）

桌面单机游戏。**美术：Dungeon Crawl Stone Soup rltiles 公有素材**（`assets/`，22 张，授权见 `assets/CREDITS.txt`）+ 程序绘制兜底；音效为 numpy 合成。

**胜利条件**：击败敌方英雄莫甘娜 **并** 攻占敌方城镇暗影堡。敌方英雄每天会主动逼近你，周一还有增援。

## 运行

```bash
cd homm3
.venv/bin/python main.py
```

（venv 已装好 pygame 2.6.1；如需重建：`python3 -m venv .venv && .venv/bin/pip install pygame`）

## 操作

| 场景 | 操作 |
|---|---|
| 冒险地图 | 左键点击目标格 → 英雄自动寻路移动；走上资源/宝箱/神器自动拾取，走上矿自动占领 |
| 冒险地图 | `E` 结束回合；`T` 进城；`TAB` 切换英雄；`M` 音效开关；`F5` 存档 `F9` 读档（存到 `save.json`） |
| 城镇 | 点击"建造"造建筑；`+1/+5` 招兵；**雇佣英雄（2500金，上限3个）**；城内多英雄可 `转1/转5` 互转部队；`ESC` 返回 |
| 战斗 | 点格子移动 / 点敌人攻击（远程可直接射击）；`D` 防御 `W` 等待 |
| 战斗魔法 | `1` 魔法箭 `2` 闪电术 `3` 减速术 `4` 急行术 `5` 治疗术 `6` 火球术（六边形溅射），选完点目标；每轮限一次 |
| 市场 | 城内建造"市场"后可买卖资源（木/矿 250 卖 500 买，水晶 500 卖 1000 买） |

## 机制（当前）

- 26x16 随机地图：地形障碍、14 处资源、6 矿、宝箱、6 件宝物（地图不同色菱形）、12 组野怪（越远越强，深处有绿龙）
- **宝物装备**：7 种宝物（武器/防具/头/饰品槽），拾取自动装备，加攻击/防御/魔力/法力/士气/运气，侧栏可查看
- **士气**：战斗中每单位行动后有 5%×士气 概率立即再行动；**运气**：攻击有 5%×运气 概率双倍伤害（战斗日志可见 🍀）
- **多英雄**：城内雇佣英雄（最多3个），各自独立移动/部队/宝物/法力，TAB 切换；城内可在英雄间转移部队
- **双阵营**：人类城堡（枪兵→骑士 6 阶）vs **亡灵大军**（骷髅兵/僵尸/幽灵/吸血鬼/巫妖/骨龙）；吸血鬼攻击吸血恢复自身，巫妖远程，敌将 14 天后带吸血鬼、28 天后带巫妖
- **混编士气**：部队混编两个阵营（如人类+亡灵）士气 -1（宝物可抵消）
- **敌方 AI**：敌将莫甘娜（每天逼近最近的玩家英雄、途经野怪自动开打、每周亡灵增援）+ 敌城暗影堡（亡灵守军，攻占后归你）
- 6 城堡兵种 + 6 野怪；伤害含攻防修正、近战反击；战后按幸存者更新部队
- **六边形战棋 13×9**（H3 同款尖顶六边形，odd-r 偏移），速度决定行动顺序；**6 种战斗魔法**（含治疗、六边形溅射火球）；AI vs AI 自动战斗（敌将打野怪用）
- **市场交易**：造市场后资源↔金币互换（卖低买高），缺水晶造高级建筑时可应急
- **亡灵祭坛**：地图上 3 座紫色祭坛，每周可领取一批免费亡灵兵（注意混编士气惩罚）
- **程序合成音效**（numpy 波形合成，零素材）：脚步/拾取/开战/近战/箭矢/施法/治疗/建造/金币/胜利/战败 11 种，`M` 键开关
- 城镇 6+1 种建筑，每周一兵源增长；矿场每周产出；英雄经验升级加攻防/法力

## 代码结构

- `constants.py` 常量 | `entities.py` 兵种/英雄/城镇 | `world.py` 地图生成 + A* 寻路
- `combat.py` 战斗引擎 + 魔法 + 自动战斗 | `main.py` 场景、敌方 AI 回合与主循环 | `savegame.py` JSON 存读档 | `sounds.py` 合成音效 | `test_smoke.py` 冒烟测试
