> 定位：**系统全部对外 HTTP API 的契约文档**——地址、出入参、报文样例、坑。
> 配套：概要设计.md 中各模块引用本文接口编号（如 I-12）；代码变更新增接口时**先改本文再写码**。

## 一、东方财富系

### I-01：东财 7×24 滚动快讯（np-listapi，采集主通道）
- **地址**：`https://np-listapi.eastmoney.com/comm/web/getFastNewsList?client=web&biz=web_724&fastColumn=102&sortEnd={sortEnd}&pageSize=50&pageNo={page}&req_trace={毫秒时间戳}`
- **方式**：GET（无鉴权，UA 浏览器串）
- **入参**：

| 参数名 | 说明 | 示例/默认值 |
|---|---|---|
| client / biz | 固定 | `web` / `web_724` |
| fastColumn | 快讯栏目 ID | `102` |
| sortEnd | 翻页游标（首页空串，之后取上页返回值） | `""` |
| pageSize / pageNo | 分页 | `50` / `1` 起递增 |
| req_trace | **必填**毫秒时间戳，缺失报缺参数 | `int(time.time()*1000)` |

- **出参**：`data.fastNewsList[].{code,title,summary,showTime,stockList[]}`、`data.sortEnd`（下页游标）；stockList 元素形如 `"1.600525"`（1=沪 0=深），取点号后 6 位；showTime 已是 `YYYY-MM-DD HH:MM:SS`
- **坑**：翻页靠游标非页码；回补上限约 4 个交易日（max_pages=40）；code 拼 `finance.eastmoney.com/a/{id}.html`
- **报文样例（示意）**：

```json
{"code": 1, "data": {"fastNewsList": [
  {"code": "202609181030123456", "title": "某公司中标海外大单",
   "summary": "公告称合同金额约 12 亿元……", "showTime": "2026-09-18 10:30:12",
   "stockList": ["1.600525"]}],
 "sortEnd": "2026-09-18 10:29:58"}}
```

- **调用方**：`fetchers/eastmoney_fast.py`

### I-02：东财资讯全文搜索（search-api-web，JSONP，宏观/地缘关键词）
- **地址**：`https://search-api-web.eastmoney.com/search/jsonp?cb=cb&param={URL编码的JSON}`
- **方式**：GET（curl 子进程优先，失败降级 urllib+SSL 降级）
- **入参**：`param` 为 URL 编码 JSON：`{"uid":"","keyword":"制裁","type":["cmsArticleWebOld"],"client":"web","clientType":"web","clientVersion":"curr","param":{"cmsArticleWebOld":{"searchScope":"default","sort":"default","pageIndex":1,"pageSize":8,"preTag":"<em>","postTag":"</em>"}}}`
- **出参**：`result.cmsArticleWebOld[].{title,content,url,date,mediaName}`（title/content 含 `<em>` 需清洗）
- **坑**：JSONP 需剥 `cb(...)` 壳；模糊匹配噪音大→标题必须含搜索词/扩展词二次过滤；`[expand]` 分组词打主题 tag
- **报文样例（示意）**：

```json
cb({"result": {"cmsArticleWebOld": [
  {"title": "<em>制裁</em>清单再扩容", "content": "……",
   "url": "https://finance.eastmoney.com/a/202609181234.html",
   "date": "2026-09-18", "mediaName": "媒体财讯"}]}})
```

- **调用方**：`fetchers/eastmoney_search.py`

### I-03：东财 push2 批量行情（ulist，验证层次日回看）
- **地址**：`{node}/api/qt/ulist.np/get?fltt=2&fields=f2,f3,f12,f14&secids={secids}`，node 轮询 `https://push2.eastmoney.com` → `http://push2.eastmoney.com` → `http://push2delay.eastmoney.com`
- **方式**：GET（curl 子进程，代理(ALL_PROXY，默认 127.0.0.1:7890)/直连各一轮）
- **入参**：`fltt=2`（数值格式化）、`fields=f2,f3,f12,f14`（价/幅/码/名）、`secids=1.600519,0.000001`（沪 1. / 深·北兜底 0.）
- **出参**：`data.diff[].{f2 最新价,f3 涨跌幅%,f12 代码,f14 名称}`
- **坑**：push2 CDN 个别节点瞬断，多节点+代理直连全排列重试（**勿改 urllib 直连**）；停牌股 f2=0 / f3 非数值，不能计入命中统计
- **报文样例（示意）**：

```json
{"data": {"diff": [
  {"f2": 3.00, "f3": -0.33, "f12": "000981", "f14": "山子高科"},
  {"f2": 1450.0, "f3": 1.02, "f12": "600519", "f14": "贵州茅台"}]}}
```

- **调用方**：`scripts/review.py`

### I-04：东财 push2 板块成分股（clist，产品传导第 2 步）
- **地址**：`{host}/api/qt/clist/get?pz=100&po=1&np=1&fltt=2&invt=2&fid=f3&fs=b:{板块代码}&fields=f12,f14&pn={页码}`，host 轮询 `http(s)://80.push2.eastmoney.com`、`http(s)://90.push2.eastmoney.com`
- **方式**：GET（curl 子进程 × host× 直连/代理 × 3 重试）
- **入参**：`fs=b:BK1015`（板块）、`pn` 1 起最多 10 页、其余固定
- **出参**：`data.diff[].{f12,f14}`、`data.total`（分页终止）
- **坑**：同 I-03 CDN 问题；空响应（非 `{` 开头）视为失败重试；结果当日缓存 `data/board_cache.json`
- **报文样例（示意）**：

```json
{"data": {"total": 86, "diff": [
  {"f12": "600525", "f14": "长园集团"}, {"f12": "300750", "f14": "宁德时代"}]}}
```

- **调用方**：`scripts/product_lookup.py`（match_score.py 间接）

### I-05：东财搜索联想 suggest（公司名↔代码 / 产品词↔板块）
- **地址**：`https://searchapi.eastmoney.com/api/suggest/get?input={URL编码词}&type=14&token=D43BF722C8E33BDC906FB84D85E326E8&count={n}`
- **方式**：GET（lookup 用 urllib；product_lookup/expand 用 curl）
- **入参**：`input` 查询词、`count` 5（lookup）/8（板块）；token 为网页公开值非私钥
- **出参**：`QuotationCodeTable.Data[].{Code,Name,Classify,SecurityTypeName}`；Classify=`AStock`（股）/`BK`（板块）
- **坑**：必须按 Classify 过滤（同名港股/美股/基金干扰）；BK 匹配需名称互含防「电池」误配
- **报文样例（示意）**：

```json
{"QuotationCodeTable": {"Data": [
  {"Code": "002475", "Name": "立讯精密", "Classify": "AStock", "SecurityTypeName": "深A"},
  {"Code": "BK1015", "Name": "固态电池", "Classify": "BK", "SecurityTypeName": "板块"}]}}
```

- **调用方**：`scripts/lookup.py`、`scripts/product_lookup.py`、`scripts/expand_products.py`

### I-07：东财数据中心·龙虎榜席位明细（RPT_OPERATEDEPT_TRADE）

- **入参**：`filter=(SECURITY_CODE="000981")`（双引号需 URL 编码）；交易日倒序+榜内名次正序

- **报文样例（实测，2026-09-17 山子高科买一席位）**：

```json

  "TRADE_ID": "100414500", "OPERATEDEPT_NAME": "深股通专用",

  "BUY_AMT_REAL": 187575742.52, "SELL_AMT_REAL": 46263128.0,
```

## 二、巨潮资讯系

### I-12：巨潮历史公告查询（hisAnnouncement，公告/司法双通道）
- **地址**：`http://www.cninfo.com.cn/new/hisAnnouncement/query`（**HTTP**）
- **方式**：POST（application/x-www-form-urlencoded）
- **入参**：

| 参数名 | 说明 |
|---|---|
| stock | **必须「代码,orgId」双段**（orgId 走 I-13 现查），只传代码返回 0 |
| searchkey | 全文词（司法通道：诉讼/冻结/破产重整/司法拍卖） |
| category | 类别（业绩预告 category_yjygjxz_szsh / 权益分派 / 股权激励 / 增发）；**对诉讼类无效回退默认流** |
| seDate | `2026-09-12~2026-09-14`（**紧凑格式，带空格返回 0**） |
| pageNum/pageSize | 1 / 30（类别通道 50）；其余（column=szse、tabName=fulltext、isHLtitle=false 等）固定 |

- **出参**：`announcements[].{announcementId(去重键),announcementTitle(含<em>需清洗),announcementTime(毫秒时间戳),adjunctUrl(PDF相对路径,拼 static.cninfo.com.cn),secCode,secName(官方标注→权重1.2)}`
- **坑**：WAF 必须 Referer+浏览器 UA+X-Requested-With 否则 403；全市场 2000+/天必须「类别+关键词」双滤；多关键词命中按 announcementId 去重；sleep 0.3s 限速
- **报文样例（示意）**：

```json
{"announcements": [{
  "announcementId": "1223456789", "secCode": "600519", "secName": "贵州茅台",
  "announcementTitle": "贵州茅台：<em>关于投资</em>设立产业基金的公告",
  "announcementTime": 1758163200000,
  "adjunctUrl": "finalpage/2026-09-18/1223456789.PDF"}]}
```

- **调用方**：`fetchers/cninfo_announce.py`（`fetchers/cninfo_legal.py` 复用其 `_query`/`_post_form`）

### I-17：知乎用户想法 Pins（关注人动态，匿名通道）

### I-18：人民法院公告网公告列表（rmfygg，Liferay portlet）
- **地址**：
  - 预热（GET，取 JSESSIONID）：`https://rmfygg.court.gov.cn/web/rmfyportal/noticeinfo`
  - 数据（POST）：`https://rmfygg.court.gov.cn/web/rmfyportal/noticeinfo?p_p_id=noticelist_WAR_rmfynoticeListportlet&p_p_lifecycle=2&p_p_state=normal&p_p_mode=view&p_p_resource_id=initNoticeList&p_p_cacheability=cacheLevelPage&p_p_col_id=column-1&p_p_col_count=1`
- **方式**：GET 预热 + POST（application/x-www-form-urlencoded）
- **入参**（表单，DataTables 协议全必填）：
  - `_..._aoData=[{"name":"sEcho","value":3},{"name":"iColumns","value":6},{"name":"sColumns","value":",,,,,,,"},{"name":"iDisplayStart","value":0},{"name":"iDisplayLength","value":15},{"name":"mDataProp_0..5","value":null}]`
  - `_..._flag=init`、`_..._noticeTypeVal=全部`、`_..._sourceTypeVal=全部`、`_..._IEVersion=ie`，其余空串
- **出参**：`{iTotalRecords, data[].{noticeCode/uuid(去重键),tosendPeople(受送达主体→股票匹配),noticeType,court,noticeContent(截500字),publishDate}}`
- **坑**：**请求头完整度敏感**——精简 headers 返回空 data 但 HTTP 200（origin/sec-fetch-*/accept-language 全套必带）；aoData 缺任一 mDataProp 同样空 data；curl schannel TLS 失败(rc=35)自动切 urllib 会话+SSL 降级；每页 15 条 sleep 1s
- **报文样例（示意）**：

```json
{"iTotalRecords": 12345, "data": [{
  "noticeCode": "320000240918001", "uuid": "a1b2c3d4-e5f6-",
  "tosendPeople": "山子高科股份有限公司", "noticeType": "破产",
  "court": "某某市中级人民法院", "publishDate": "2026-09-18 00:00:00",
  "noticeContent": "本院根据某某的申请，裁定受理……"}]}
```

- **调用方**：`fetchers/rmfygg_notice.py`

## 四、大模型

### I-19：智谱 GLM Chat Completions（分类/HITL/人物甄别/滑块识别四用）
- **地址**：`https://open.bigmodel.cn/api/paas/v4/chat/completions`
- **方式**：POST（JSON）
- **入参**：`{"model":"glm-4v-flash","temperature":0.1,"messages":[{"role":"user","content":[...]}]}`；content 文本块 `{type:"text"}`，图片块 `{type:"image_url",image_url:{url:"data:image/png;base64,..."}}`
- **出参**：`choices[0].message.content`（约定 JSON 数组，宽松解析截取首 `[` 到末 `]`）
- **坑**：key 取环境变量 `GLM_VISION_API_KEY`（缺省 zsh 登录 shell 兜底）；TLS 拦截降级 unverified 重试；新闻批 8 条/请求；**双图并发 400（16K 上下文）→ 滑块只发单图**；失败/无 key 静默降级回正则
- **报文样例（示意，事件分类）**：

```json
{"choices": [{"message": {"content": "[{\"id\":1,\"stocks\":[\"600519\"],\"event\":\"订单合同\",\"impact\":3,\"confidence\":0.9,\"reason\":\"公告披露12亿大单\"}]"}}]}
```

- **调用方**：`scripts/llm_classify.py`；`match_score.py`/`ent_mine.py` 复用 call_llm；`zxgk_check.py` 独立 urllib 同端点（image_url 模式）

## 五、推送通道

### I-20：Server酱 Turbo（备用通道）
- **地址**：`https://sctapi.ftqq.com/{SendKey}.send`
- **方式**：POST（表单：`title` + `desp` Markdown）
- **出参**：响应文本含 `"code":0` 即成功
- **坑**：免费 5 条/天；单消息 ~32KB 截断（保概览+宏观）；SendKey 来源 --key > env SERVERCHAN_SENDKEY > zsh shell > push_config.json；urllib（OpenSSL 栈）发送——沙箱下 curl/schannel 无法建 TLS 凭据
- **报文样例（示意）**：

```json
{"code": 0, "message": "", "data": {"pushid": "12345", "readable": "ok"}}
```

- **调用方**：`scripts/push_channels.py`、`push_daily.py`（经 channels）、`push_md.py`

### I-21：企业微信群机器人 webhook（主通道）
- **地址**：`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key={机器人key}`
- **方式**：POST（JSON：`{"msgtype":"markdown","markdown":{"content":"..."}}`）
- **出参**：`{"errcode":0}` 即成功
- **坑**：单条 4096 字节（按 3800 分段留头部余量）；20 条/分钟（分段 sleep 1s）；**markdown 不支持表格**→表格行转「 · 」列表、`|---|` 行丢弃；续条标题加 `(续N)`；key 从完整 webhook URL 截取（`key=` 后到 `&`）
- **报文样例（示意）**：

```json
{"errcode": 0, "errmsg": "ok"}
```

- **调用方**：`scripts/push_channels.py`、`scripts/push_md.py`

## 六、企业数据

### I-22：企查查 MCP 流式接口（司法风险批量精查）
- **地址**：`https://agent.qcc.com/mcp/{server}/stream`，server ∈ {`company`,`operation`,`risk`,`ipr`}
- **方式**：POST（JSON-RPC 2.0；响应 JSON 或 SSE 流逐行 `data:` 解析）
- **入参**（三步握手）：
  1. `{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"qcc-batch","version":"0.1"}}}`
  2. `{"jsonrpc":"2.0","method":"notifications/initialized"}`
  3. `{"jsonrpc":"2.0","id":N,"method":"tools/call","params":{"name":"get_dishonest_info","arguments":{"searchKey":"9144030059070463XP"}}}`
- **出参**：`result.content[0].text`（JSON 字符串需二次解析；查无实体=`{"无匹配项":"..."}`）；error 码 `100002` 境外 IP / `300008` 积分不足 / `401` 凭证无效（HTTP 4xx/5xx 时错误码也在 body，优先解析 body）
- **坑**：**只收国内 IP**——session `trust_env=False` 强制绕过系统代理（挂代理会 100002）；server 间最小间隔 0.15s；429 指数退避 3 次；300008 自动切下一 token（config.json 顶层 tokens 数组按序耗尽）、401 永久拉黑；1 积分/tool 调用（精查 4 字段×TOP20=80/天 < 每日赠送 100）；断点续爬 `_progress.json`
- **报文样例（示意）**：

```json
{"jsonrpc": "2.0", "id": 3, "result": {"content": [
  {"type": "text", "text": "{\"Result\":{\"TotalCount\":0,\"Items\":[]}}"]}}
```

- **调用方**：`tools/qcc-mcp-batch/qcc_mcp.py`（`scripts/qcc_legal_check.py` 子进程调用并解析落盘 JSON）
