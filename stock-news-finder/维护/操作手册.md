## 2. 日常操作（按频率排列）

### 2.1 每日主流程（一条命令）

```powershell
cd stock-news-finder
scripts\run.sh        # 或 git bash 下 ./scripts/run.sh
```

8 步：采集(11源) → 词典 → LLM分类 → 打分(HITL挂起) → 推荐 → 推送(企微) → 财报日历 → 昨日复盘。
任一步失败不阻断，日报始终落 `daily/`。

### 2.2 HITL 判定（有 pending 才需要，日增个位数）

```
1. 打开 output/hitl_pending_yyyymmdd.md
2. 表格里把 #判定结果 占位符改为 正/负/中性，#判定原因 填简短理由
   （预判三列是系统参考勿动；判定原因=学习语料）
3. python scripts\hitl_review.py --import output\hitl_pending_yyyymmdd.md
4. 重跑当日打分生效：python scripts\match_score.py
5. 周报统计：python scripts\hitl_review.py --stats
```

### 2.3 各专项通道（手动触发）

| 场景 | 命令 | 说明 |
|---|---|---|
| 法人风险半自动（P0） | `python scripts\legal_check.py [--top 30]` | 出待核清单→人工查执行网→`--result` 导入 |
| 执行网全自动（方案A） | `python scripts\zxgk_check.py [--one 名字\|--names a,b]` | playwright+GLM打码；会滑浏览器窗口属正常 |
| 实体层①公司新闻 | `python scripts\ent_mine.py [--date yyyymmdd\|--backfill]` | 词典命中→ent_company_news |
| 实体层②人物新闻 | `python scripts\ent_mine.py --mine-person [--backfill]` | LLM 抽取+姓名修正→ent_person_news |
| 实体层③法人种子 | `python scripts\ent_mine.py --seed-person` | F10 画像→ent_person_company |
| 实体三表统计 | `python scripts\ent_mine.py --stats` | 库存与大小 |
| 企查查（已弃用） | `python scripts\qcc_legal_check.py --dry-run` | 保留备用 |

### 2.4 跨机同步（git 两段式命令）

- 对话内说「**推送列表**」→ 只读展示待推送内容
- 确认后说「**推送github**」→ add(排除噪声)→commit→密钥自检→push
- 手动：`git pull origin main`（Windows pull 撞 match_score.py 冲突时找 agent 合并）
- output/raw/daily 均不入库：跨机数据靠 `export_sync.py` → FTP → `import_to_mongo.py`

## 4. 排障速查（踩坑实录，均在设计文档有详细记录）

| 症状 | 原因 | 处理 |
|---|---|---|
| 东财 push2 接口瞬断 | CDN 不稳 | curl 子进程+多节点+代理/直连全排列（代码已内置） |
| 巨潮 403 / 空数据 | WAF 要 Referer / 请求头不全 | 带全套浏览器头（fetcher 已内置）；seDate 紧凑格式 |
| 公告网列表空 | headers 精简被拒 | origin/sec-fetch-*/accept-language 全套必带 |
| 信用中国/执行网 curl 拿到 JS 壳 | 瑞数反爬 | 执行网走 playwright（方案A）；信用中国放弃 |
| GLM 双图 400 | 16K 上下文限制 | 单图模式；大图先压缩（glm4v-image-compress） |
| GLM 批次全失败 KeyError '"id"' | prompt JSON 花括号未转义 | `.format()` 模板内 {{}} 双写（D28） |
| 企查查 100002 境外IP | 挂代理 | trust_env=False 已内置；TUN 模式需直连规则 |
| Windows 控制台中文乱码 | GBK 代码页 | `chcp 65001` / PYTHONIOENCODING=utf-8 |
| push_daily 推送炸 | 废弃 push 覆盖导入 | 已修复（D20），走 push_channels |
| 推荐全是产品传导股 | 传导刷屏 | 已由推荐层提纯（D19），属预期 |
