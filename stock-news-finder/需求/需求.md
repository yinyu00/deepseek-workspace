# 股票新闻分析系统 · 需求文档

> 版本：v0.7（2026-09-13）
> 状态：原型已跑通部分功能，本文档梳理完整需求，作为后续迭代基线
> 定位声明：**研究漏斗**——每天从全市场新闻中筛出少量候选股票供人工研究，**不是**自动交易系统
> 运行模式：**手动触发**（v0.3 起，定时任务已移除；理由见 D10）

## 1. 系统目标

通过网络新闻发现可能上涨的股票：

- 输入：每日财经新闻（快讯、公告、研报摘要）
- 处理：新闻 → 关联股票 → 事件分类 → 打分排序
- 输出：每日信号报告（TOP30 候选 + 事件依据 + 原文链接）
- 原则：可解释性优先——每条信号必须能回答"为什么推荐"

## 2. 分层架构

```
采集层 → 解析层 → 关联层 → 信号层 → 验证层（未建） → 展示层
```

| 层 | 职责 | 现状 |
|---|---|---|
| 采集层 | 多源新闻抓取、去重 | ✅ **插件化架构（v0.3）**：一源一模块 fetchers/<type>.py，动态加载；东财+华尔街见闻双源 |
| 解析层 | 事件分类、情感/影响判断 | ✅ GLM API 分类（9类事件）+ 正则规则降级 |
| 关联层 | 新闻 → 股票映射（三条路径） | ✅ 公司直接命中 + 产品板块传导；隐性关联未做 |
| 信号层 | 综合打分排序 | ✅ 影响分×置信度×命中强度×时效衰减 |
| 验证层 | 历史回测、信号有效性统计 | ❌ 未建（依赖 daily/ 历史积累） |
| 展示层 | 报告查看、告警推送 | ✅ Markdown 日报；推送未做 |

## 5. 关键设计决策记录

| # | 决策 | 理由 |
|---|---|---|
| D1 | 数据源/词典全部配置文件驱动 | 用户明确要求：动态添加、手动维护、热替换 |
| D2 | LLM 分类失败自动降级正则，主流程不中断 | 定时任务无人值守，可用性优先 |
| D3 | 产品传导权重 0.6 低于直接命中 1.0 | 传导受益非专属，确定性低 |
| D4 | 深市词典暂缺，先跑沪市 | 用户决策：深市 Excel 未找到，后续补充 |
| D5 | push2 接口用 curl 子进程 + 多节点重试 | 本机网络实测：urllib 直连频繁瞬断 |
| D6 | 日报同日覆盖（最新一次为准） | 简单；回测以最终信号为准 |
| D7 | 东财采集按日期边界翻页（非固定条数），max_pages=40 安全上限 | 抓满全天；游标实测可回翻约 4 个交易日，天然支持回补 |
| D8 | 归档合并以旧归档为去重基准 | v0.2 修掉新批次自去重 bug（多源增量进不了归档）；跨源同新闻标题不同各自保留 |
| D9 | launchd plist 用 Python plistlib 程序化生成 | 手写 XML 曾出闭合标签错误；plistlib 保证结构合法 |
| D10 | **手动触发替代定时**（v0.3，定时任务已卸载） | 用户决策：采集是确定性工作，手动/会话触发零成本且灵活当场可见；代价是依赖人的节奏，历史积累可能有缺口——靠 `--since` 回补弥补 |
| D11 | 采集层插件化：一源一模块 + SPEC 接口规范 + loader 动态加载 | 新源零侵入；插件自测（selftest）强制；subagent 可按规范并行开发插件（agent 负责"生"，代码负责"跑"） |
| D12 | 深市词典来源：东财 datacenter F10 全量拉取本地过滤（filter 参数被拒） | 覆盖全、一次到位；ST/B股/退市本地过滤与沪市导入逻辑一致 |
| D13 | stockList 官方标注权重 1.2 > 文本命中 1.0 | 官方标注无歧义，权威性最高；独有命中证明其价值（文本会漏配） |
| D14 | 搜索源三层过滤，标题必须含主题词 | 东财搜索模糊匹配噪音大（正文擦边）；宏观事件标题必然点题，该启发式实测将 68 条洗净为 56 条零噪音 |
| D15 | 宏观新闻独立板块不进主排名 | 地缘事件与个股的传导路径长且不确定，混入排名会稀释个股信号；先展示后判断 |
| D16 | 微信推送选 Server酱（个人消息）而非群机器人 | 用户选择中转方案；免费 5 条/天对日报场景足够；注意：推送目标是个人微信服务号消息，非微信群 |
| D17 | 知乎源只做「想法 pins」匿名通道；回答/文章/关注流需登录 cookie 暂不支持 | 实测（2026-09-13）：activities 匿名返回空 data、answers/articles 匿名 401、pins 匿名 200 可用；后续如需回答，可加 ZHIHU_COOKIE 环境变量扩展，不破坏现有结构 |

## 8. 运行手册（手动触发）

## 9. 术语约定

- **命中**：新闻文本中出现词典词项（公司名/别名/产品词）
- **传导**：产品词 → 板块成分股的间接关联
- **信号分**：单条新闻对单只股票的打分；**综合分**：该股当日全部信号分之和
- **日报**：daily/yyyymmdd.md，当日最终信号快照
- **插件**：fetchers/<type>.py 采集器模块（fetch + selftest 接口，见 fetchers/SPEC.md）
